<ins>**Robust, Effective and Resource Efficient Deep Neural Network for Intrusion Detection in IoT networks**</ins>

**Overview**

This project presents a robust, effective, and resource-efficient deep neural network (DNN) approach for intrusion detection in Internet of Things (IoT) environments. It investigates how deep-learning-based security solutions can deliver effective intrusion detection while addressing the computational and resource constraints associated with IoT deployments.

The project evaluates the proposed approach against state-of-the-art methods, focusing on detection performance, adversarial robustness, and resource efficiency. It also includes a comparison with a TensorFlow Lite implementation to investigate the potential benefits of lightweight model deployment.

**Key Contributions**

- IoT Intrusion Detection: Implementation of a deep neural network for security monitoring in IoT environments.
- Robustness Evaluation: Assessment of model robustness as part of the comparison with existing approaches.
- Resource Efficiency: Investigation of resource savings alongside detection performance.
- Benchmarking: Comparative evaluation against state-of-the-art approaches.
- Lightweight Deployment: Inclusion of a TensorFlow Lite model comparison, implemented in pt737_tensrlte.py.

**Technologies**

- Python
- Deep Neural Networks (DNNs)
- TensorFlow Lite
- Repository Contents

The repository contains the implementation of the proposed DNN-based intrusion detection approach and supporting scripts for performance evaluation and comparison, including pt737_tensrlte.py.

**Research Publication**

This work was published in the Proceedings of the 8th ACM Workshop on Cyber-Physical System Security (ACM CPSS 2022).
